PENTING - CARA MEMAKAI
- File .html di paket ini adalah cadangan. Kalau dibuka langsung dari komputer, muncul banner
  "Penyimpanan bersama belum tersambung" karena data disimpan di penyimpanan claude.ai, bukan di file.
- Untuk dipakai sehari-hari, buka halaman "Audit Internal Produksi" di claude.ai dengan akun yang sama.
  Versi terbaru (v5) sudah terpasang di sana dan datanya tetap.
- Agar file ini bisa jalan sendiri di website (tanpa claude.ai), bagian penyimpanan harus diganti ke
  database sendiri (mis. Supabase/Firebase). Itu langkah terpisah.

CATATAN SKOR
- Skor seksi = M / (M + DM) x bobot seksi. Menambah poin checklist tidak mengubah bobot seksi
  dan tidak mengubah skor audit lama; nilai tiap poin di seksi itu menjadi bobot / jumlah poin.
- Poin tambahan diberi nomor T1, T2, ... dan bisa dinonaktifkan (tidak dihapus) agar jawaban lama tetap ada.
